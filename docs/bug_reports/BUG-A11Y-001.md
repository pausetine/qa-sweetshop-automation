## Steps to reproduce

1. Navigate to `https://sweetshop.vivrichards.co.uk/basket`.
2. Open Chrome Developer Tools (`F12`).
3. Navigate to the Console tab.
4. Run the following JavaScript:

   `document.querySelectorAll('[id="name"]')`

5. Inspect the returned elements and check whether multiple elements share the same ID.
6. Alternatively, run the automated test using:

   `python -m pytest tests/test_accessibility.py -v -s`

## Expected result

All HTML elements on the Basket page should have unique `id` attribute values to maintain valid HTML and support reliable accessibility relationships and DOM references.

## Actual result

The automated test detected the duplicated HTML ID `name` on the Basket page.

The test failed with the following assertion:

`AssertionError: Duplicate HTML IDs found on /basket: ['name']`

The Login page passed the same duplicate-ID test, indicating that this particular issue was detected on the Basket page.

## Impact and notes

Duplicate HTML IDs violate the uniqueness requirement for document identifiers and can create ambiguity when elements are referenced by JavaScript, CSS selectors, labels, or accessibility attributes.

Potential accessibility consequences include incorrect associations between labels and form inputs. However, direct screen-reader impact has not yet been demonstrated.

**Suggested fix:** Identify the elements sharing `id="name"` and assign distinct, descriptive IDs. Update any corresponding `for` attributes, JavaScript references, or other dependencies.

**Retest criteria:** Rerun TC-A11Y-001 and confirm that no duplicate HTML IDs remain on the Basket page.
